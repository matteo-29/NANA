# NANA & Matteo — Online Check-in App

Source code for the wedding online check-in web app (design inspired by ANA's
online check-in flow). This is a standalone fullstack app (Express + Vite +
React + Supabase) and is versioned here for reference only — it is deployed
separately and does not affect the GitHub Pages site served from the
repository root (`index.html` / `entry.html`).

## Stack
- Frontend: React + Vite + Tailwind CSS + shadcn/ui
- Backend: Express
- Database: Supabase (Postgres)

## Development
```
npm install
npm run dev
```
